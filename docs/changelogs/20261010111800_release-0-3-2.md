# Release 0.3.2 metadata

## Participants

Andrei Makarov

## Decisions

Cut 0.3.2 after published 0.3.1. User-visible work since the 0.3.1 tag:
`graphql { identity ... }` (RFC 0007) for keyless views, and schema-build
error text that names `identity` alongside `self.primary_key` and `disable!`.

CHANGELOG 0.3.1 restored to the published one-bullet text. Identity DSL bullets
live under 0.3.2 dated 2026-10-10.

Version constant is 0.3.2. Path gem pins in Gemfile.lock and appraisal
lockfiles match.

Docs-only notes (Rails composite PK alignment, partitions/shards unsupported,
federation unsupported) stay out of CHANGELOG.md.

make release (usr/bin/release.rb) still owns gem build, gem push, git tag, and
GitHub release. This pass only prepares metadata.

## Effects

PATH specs for activeadmin-graphql in Gemfile.lock,
