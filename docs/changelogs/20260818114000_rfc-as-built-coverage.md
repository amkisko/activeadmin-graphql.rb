## Decisions

Starter pack RFC 0001 and RFC 0002 is not enough. Each public contract named in RFC 0002 gets its own Informational Stable RFC with Describes pinned to the current version.

As-built Informational RFCs are Stable. A later change to those contracts is a new Standards Track RFC.
