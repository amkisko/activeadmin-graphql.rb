# Release 0.3.1 metadata

## Participants

Andrei Makarov

## Decisions

Cut 0.3.1 after published 0.3.0. User-visible work: GraphQL identity for
database views and nonconventional primary keys; fail-closed when a model has
neither a primary key nor an `id` column without configuration; and
`graphql { identity ... }` (RFC 0007) for keyless views with a virtual
composite id.

CHANGELOG 0.3.1 dated 2026-10-10. Version constant is 0.3.1. Path gem pins in Gemfile.lock and appraisal lockfiles match.

Docs-only and pray-tooling commits since 0.3.0 stay out of CHANGELOG.md.

make release (usr/bin/release.rb) still owns gem build, gem push, git tag, and GitHub release. This pass only prepares metadata.
