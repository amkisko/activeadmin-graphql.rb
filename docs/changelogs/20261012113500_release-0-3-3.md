# Release 0.3.3 metadata

## Participants

Andrei Makarov

## Decisions

Cut 0.3.3 after published 0.3.2. User-visible work since the 0.3.2 tag:
`graphql_resource_enabled_default` and `enable!` opt-in, surface toggles for
queries, mutations, run-actions, policies, `registered_resource`, and
`belongs_to`, plus GraphQL capabilities (RFC 0008). Defaults stay `true` so
0.3.x schema shape is unchanged unless an app opts in to narrower surfaces.

CHANGELOG Unreleased bullets moved under 0.3.3 dated 2026-10-12.

Version constant is 0.3.3. Path gem pins in Gemfile.lock and appraisal
lockfiles match.

Internal `stringify_attrs` safe-navigation cleanup stays out of CHANGELOG.md.

make release (usr/bin/release.rb) still owns gem build, gem push, git tag, and
GitHub release. This pass only prepares metadata.
